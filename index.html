ESP32 firmware flashing, directly from your browser.

A lightweight ESP Web Tools portal for the ESP32 Dev Module. No desktop flashing application is required when using a supported browser and USB connection.

ESP32 · Browser Flasher

Install Home automation firmware

Connect the ESP32 by USB, close programs that may be using its serial port, then press the button. ESP Web Tools will handle browser serial-port selection and the flashing process.

Web Serial is not available here. Use a current Google Chrome or Microsoft Edge browser on desktop.
This page must be opened over HTTPS (GitHub Pages provides HTTPS).

Supported board

ESP32 Dev Module

Chip family: ESP32

USB connection: USB-to-UART or a compatible USB serial interface.

Before flashing

  • Use a data-capable USB cable.
  • Back up anything important on the device.
  • Do not disconnect power while flashing.
  • Allow the browser to access the serial port.

How to flash

1
Connect the ESP32 Dev Module to your computer with a USB data cable.
2
Open this GitHub Pages website in Google Chrome or Microsoft Edge.
3
Press Flash Firmware and select the ESP32 serial port in the browser dialog.
4
Wait until ESP Web Tools reports that installation is complete. Do not unplug the board during the process.
5
Reset the ESP32 and verify that the new Home automation firmware starts normally.

Important firmware note

The supplied firmware filenames are the four separate ESP32 images from your build. ESP Web Tools' current documentation recommends a merged ESP32 binary for modern ESP-IDF/ESP32 builds because it cannot dynamically patch flash mode, frequency and size like esptool. If your exact firmware was produced by Arduino IDE and the four-part manifest fails, create and publish a merged binary using the instructions in the project README.

Troubleshooting

  • “Failed to download manifest”: open /manifest.json directly. It must return JSON, not a GitHub 404/HTML page.
  • BIN download fails: open each firmware URL directly and verify it downloads as a binary file. Check spelling and capitalization.
  • Serial port is missing: install the USB-UART driver used by your ESP32 board, reconnect it, and check the operating system's device list.
  • Connection fails: close Arduino Serial Monitor/PlatformIO/other serial applications, use a known-good USB data cable, then retry.
  • Manual bootloader: hold BOOT, press/release EN/RESET, keep BOOT held briefly, then release BOOT and retry the connection.
  • GitHub Pages 404: confirm Pages is publishing the correct branch/folder and that index.html is in that published location.
  • Old manifest/cache: hard-refresh the page or open it in a private window after changing firmware files.
  • ESP32-S3: this portal targets the ESP32 Dev Module. ESP32-S3 has different USB/serial behavior; use a separate S3 build/manifest if you later add S3 support.
